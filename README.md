# 🌍 World Flags Game Quiz EN-ES
## 🎮 Description
Test your world knowledge with this interactive and visually stunning game. Guess the flag, official language, or capital city of countries around the globe. Each correct answer earns you points… but be careful! One mistake resets your score and forces you to start over. Have fun with your friends and family!

## ✨ Key Features
- 🏳️ **Three Game Modes**: Flag → Country, Flag → Official Language, Flag → Capital
- 🌐 **Bilingual**: Switch between Spanish and English instantly
- 🖼️ **Modern Design**: Cards with a glass effect, shadows, and smooth animations
- ⚡ **Fast Dynamics**: Immediate response, visual feedback (green ✅ / red ❌)
- 📊 **Scoring System**: Win-win streak keeps you on the edge of your seat
- 🎯 **Capital Mode**: Displays the country's name to help you remember its capital city

## 🧠 How to Play?
1. Choose a **mode** (country, language, or capital)
2. Look at the **flag** (and the country name if you're in capital mode)
3. Select the correct answer from **4 options**
4. **+1 point** if you're correct and move on to the next flag
5. **Careful!** If you're wrong, you go back to **0 points**

Perfect for **travelers, students, curious minds**, or any geography enthusiast.

| 🌎 Data updated from **RestCountries API** — over 250 countries included.
